## Spotify for Nari

Your Spotify library in [Nari](https://github.com/NaviVani-dev/Nari)!

Supports streaming, library and downloads, requires a Spotify Premium subscription to work.

### WARNING
Spotify is migrating some accounts into a new secure DRM for playback, which this plugin can't handle, if you get a lot of error about Spotify not accepting keys, sadly your account has been migrated to this and you can't revert it.

What you can do:
- Use another music provider like Deezer or Youtube Music
- Own your music and stop using Spotify
